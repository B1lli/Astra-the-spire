# 独立卡面

26 种卡牌，每个卡牌 key 对应一张同名 PNG；普通版与升级版共用同一张对应插图。游戏通过 `src/card-art.js` 的 `CARD_ART` 读取，流派标签保留，卡牌墨色跟随角色。

## 最终方向

根据用户反馈，放弃人脸占据主体的第一版，改为动作和物品主导：武器、手势、碰撞点占画面 60–70%，脸部缺省或控制在 5% 以下；用透视、尺度差、扭转和对向受力表现张力。背景 30–40% 纯白留空，特效集中在物品本身。

- 凯尔：暗红 `#A53030`。
- 莉娅：钴蓝 `#2148B8`。
- 希尔：深绿 `#25562E`。
- 少数卡牌以平涂浅金 `#D8BD76` 强调刃口或核心；裂隙创伤用纯黑强调裂纹。
- 纸白 `#FAFAF7`；纯色色块、白色镂空、硬边日漫线条；无字、无装饰背景。
