# 全流程对照与重做

参考：[Mega Crit 官方 Steam 游戏介绍](https://store.steampowered.com/app/646570/Slay_the_Spire/?l=english)。核心特征是独立角色牌池、动态构筑、每局变化的路线、风险取舍与遗物联动。以下是对当前项目的产品审查，不是对原作完整内容规模的复刻。

| 阶段 | 旧版缺口 | 本轮实现 |
| --- | --- | --- |
| 打开游戏 | 直接开战 | 主菜单：开始 / 有存档时继续；实时 3D、多图切片、单色动态构图 |
| 选角 | 三人小队共用牌组 | 三选一、实时模型、生命、初始牌组、独有初始遗物完整展示 |
| 开局 | 遗物只有图标，缺少获得感 | 初始遗物装备确认、三选一祝福，再进入地图 |
| 路线 | 固定七层、下一层随意跳列 | 种子生成十五层，沿实际连线前进；能预览后续风险与补给 |
| 首战 | 两名敌人、三名队员、机制负担过重 | 一名角色对一名怪；基础攻击、格挡、易伤组成剑士教学牌组 |
| 角色成长 | 各角色牌混合，无明确身份 | 战利品、商店和事件奖励按所选角色过滤 |
| 目标选择 | 无箭头，指向技能与非指向技能不明确 | 曲线箭头、目标吸附、悬停预览；点击或拖动出牌；Esc / 右键取消 |
| 战斗节奏 | 每张基础牌长特写，小队共鸣必选 | 缩短普通牌特写，保留大招慢镜与命中停顿；共鸣改为可选遗物效果 |
| 战后构筑 | 已有三选一 | 保留奖励跳过、精英遗物选择，禁止重复领取 |
| 非战斗房间 | 营火、商店、事件已存在但流程不突出 | 接入地图，加入宝箱；休息/升级、买牌/移除、代价事件均回到地图 |
| 结束 / 恢复 | 无正式起始流程 | 胜负结算、再次选角，菜单继续最新冒险；存档版本隔离 |

## 基础数值

基础回合：3 能量、抽 5 张牌、手牌上限 10，回合末弃牌，牌库空时重洗。

剑士采用原作铁甲战士的基础数值结构：80 生命、99 金币、5 张 1 费 6 伤攻击、4 张 1 费 5 格挡、1 张 2 费 8 伤并施加 2 易伤的攻击；初始遗物战后回复 6。

术师与游侠保留现有原创卡牌机制：首张技能过牌、三张攻击叠盾。它们不是原作角色的逐项复制。当前是一座 15 层高塔，最终领主结束本局；不宣称包含原作全部章节、350 张牌、每日挑战或进阶难度。

## 视觉约束

黑、纸白、钴蓝三种基础色。中间色阶来自纸面网点、模型光照和抗锯齿。开屏不是单张生成图片：实时 Three.js 角色、程序化环线与斜切、三幅独立插画的局部切片和 HTML 字体分别组成。三位角色模型使用可驱动骨架部件，近战保留蹬地、冲刺、挥剑、回位。

## 验证

`npm test` 验证开局、路线合法性、牌堆、角色遗物、战斗结算、奖励、非战斗节点与存档。

`npm run simulate` 在三名角色、四个种子中跑完十五层流程，模拟的是简易策略代理，不代表玩家胜率。浏览器另行验证完整开局、目标箭头与实际出牌，以及响应式界面。
